# Complex Conditions with `while` Loops

## 📌 About the Project

This project is a Python exercise focused on practicing **complex conditional expressions**, `while` loops, and Boolean variables.

The program challenges the user to guess two secret numbers within a limited number of attempts. It continues running while attempts remain and at least one of the numbers has not been guessed correctly.

## 🎯 Objectives

- Practice `while` loops with multiple conditions.
- Understand logical operators such as `and`, `or`, and `not`.
- Work with Boolean variables (`True` and `False`).
- Use `if` statements to evaluate multiple conditions.
- Track the number of attempts remaining.
- Apply conditional logic to control program flow.

## ⚙️ How It Works

1. The program defines two secret numbers: `7` and `3`.
2. The user starts with five attempts.
3. In each round, the user enters two guesses.
4. The program checks whether each guess matches its corresponding secret number.
5. Correct guesses are recorded using Boolean variables.
6. The number of attempts decreases when at least one number remains unguessed.
7. The program ends when both numbers are guessed or the attempts run out.

## 🛠️ Technologies

- **Python 3**
- `while` loops
- `if` and `else` statements
- Boolean variables
- Logical operators
- User input with `input()`
- Formatted strings (f-strings)
